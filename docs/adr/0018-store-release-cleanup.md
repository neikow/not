# 0018 — Ready for the stores: fewer settings, About and Support

Status: accepted (2026-11-21)

## Context
not is going from a sideloaded personal app to Google Play (the Mac app stays an ad-hoc signed
download, ADR 0005), with its repository public. Settings had grown pages that only made sense
for one user (an Archive page beside the Logbook, a text importer for one old workout log, a
global widget look next to each widget's own setup), and nothing said who makes the app, where
to ask for things, or what it's built on.

## Decision
- **Archive becomes a filter.** The filter language gets `done`: completed tasks. A view whose
  query names it lists its completed tasks of any age and no open ones, so `done #work` is the
  archive of a tag. Other views keep completed tasks for a day, as before. The Settings archive
  pages and `Store::archive`/`clear_archive` go; the Logbook still lists everything done, by day.
- **Workouts' "Import from text" and the global "Look of all widgets" go** from Settings. The core
  importer stays for demo data; each widget keeps its own look settings.
- **About**: version, request a feature and report a bug (GitHub issue forms, prefilled with the
  version, platform and device), what's new (releases), source, privacy (PRIVACY.md), open-source
  licenses (generated by `scripts/licenses.py` from `cargo tree` plus the platform libraries, at
  build time), and the wger credit.
- **Support** (Ko-fi) is only in sideloaded Android builds and the Mac app. Google Play's payments
  policy only clearly allows links out for tips when they're peer-to-peer, and has rejected
  apps' donation links, so `-Pstore=play` builds leave it out. The link is a build setting
  (`supportUrl` in android/gradle.properties, `NOT_SUPPORT_URL` in apple/project.yml); empty
  hides the page.

## Consequences
- Old saved views keep working; `done` is a new word, so no query changes meaning.
- Tasks archived before this stay reachable from the Logbook and from any `done` view.
- A Play build is `./gradlew bundleRelease -Pstore=play`.
